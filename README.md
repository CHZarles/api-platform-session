# API 平台技术方案：会话精华与 Artifacts

本目录归档 2026-11-27 技术方案讨论的最终结论和主要交付物。

## 快速阅读

1. [`01-会话精华.md`](01-会话精华.md)：需求、决策、边界、关键约束和实施顺序。
2. [`02-完整技术方案.md`](02-完整技术方案.md)：面向技术人员评审的完整报告。
3. [`02-完整技术方案.html`](02-完整技术方案.html)：带目录、表格和打印样式的 HTML 版本。
4. [`03-关键决策记录.md`](03-关键决策记录.md)：技术选型和方案的 ADR 摘要。
5. [`references/`](references/)：本目录内可访问的官方资料和实践案例。

## 最终架构

```text
APISIX + Keycloak + PostgreSQL
+ 模块化单后端
+ 管理后台与开发者门户
+ 后台 Worker
+ Docker Compose

后期：ClickHouse + Kafka + Kubernetes + 在线支付
```

## 使用说明

- 技术评审优先阅读完整技术方案。
- 项目启动优先阅读会话精华中的“开发前置条件”。
- 后续方案变化优先更新关键决策记录。
- HTML 中的 Mermaid 图在支持 Mermaid 的 Markdown/文档查看器中渲染。
